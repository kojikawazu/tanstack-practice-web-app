# API instructions

親ディレクトリの `AGENTS.md` に加え、`apps/api/**` を変更する前に `../../.claude/rules/api.md` を読んで守ってください。

API 契約（エンドポイント・リクエスト/レスポンス）を変更する場合は、`docs/07-api-specification.md` を同じ変更セットで更新します。

`repositories/**` などデータアクセス・データモデルに関わる変更では、さらに `../../.claude/rules/database.md` を読み、`docs/05-data-specification.md` も同じ変更セットで更新します。
