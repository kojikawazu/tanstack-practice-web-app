# Frontend instructions

親ディレクトリの `AGENTS.md` に加え、`apps/web/**` を変更する前に `../../.claude/rules/frontend.md` を読んで守ってください。

画面・機能の振る舞いを変更する場合は、`docs/03-functional-specification.md` も同じ変更セットで更新します。

API の呼び出し契約を変更する場合は、`apps/api` 側と `packages/shared` のスキーマへの影響を確認し、`docs/07-api-specification.md` を同じ変更セットで更新します。
